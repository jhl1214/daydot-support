Current version: 1.0As of: October 20, 2026
App Store Connect 실제 제출문이 아닙니다. 이 페이지는 제출 전 검토용 제안 목록입니다. 최종 제출 전 실제 컴파일된 SDK 매니페스트, Firebase 설정, Google UMP·AdMob 설정과 앱의 현재 흐름을 확인해 데이터 유형·연결 여부·용도를 다시 판정해야 합니다. 앱스토어 등록 ID는 이 문서에 포함하지 않습니다.

수집 여부

Data Collected · Yes

Firebase Analytics와 Google Mobile Ads가 처리할 수 있는 앱·기기·광고·진단 신호가 있으므로 데이터 수집 여부는 예로 검토합니다. 일기 기록과 사진은 앱의 기본 동작에서 서버로 자동 수집하지 않지만, 이것이 SDK 처리까지 없다는 뜻은 아닙니다.

Tracking 검토

Tracking · 최종 판정 전 재검토

앱 구성은 비개인맞춤 광고 요청, publisher first-party ID 비활성화, ATT 추적 권한 요청 없음, IDFA 권한 요청 없음이지만, 확인된 GMA 매니페스트는 Device ID를 tracking=true로 보고합니다. 이 불일치를 해소하기 전에는 Tracking No를 확정된 값처럼 표시하지 않습니다. 실제 SDK 수집·Apple의 Tracking 정의·최종 컴파일 릴리스와 UMP의 지역별 메시지·선택사항을 제출 직전에 함께 확인한 뒤, 근거가 있으면 No로 갱신하고 그렇지 않으면 실제 결과에 맞게 신고하세요.

앱의 저널 흐름에서 자동 전송하지 않는 콘텐츠

현재 앱 흐름은 다음 콘텐츠를 일기 기능의 Analytics·광고 이벤트로 자동 전송하지 않도록 설계되어 있습니다. 이는 SDK가 모든 데이터를 미연결·익명으로 처리한다는 선언이 아닙니다.

  • Photos: PhotosPicker에서 사용자가 선택한 사진은 기기 내 기록에 사용하며 자동 업로드하지 않습니다.
  • Other User Content: 제목·메모·사진·날짜·검색어는 Analytics 이벤트에 넣지 않습니다.
  • Contacts: 연락처를 읽거나 업로드하지 않습니다.
  • Precise Location: 정밀 위치 권한을 요청하지 않습니다.
  • Financial or Health: 금융·건강 데이터를 수집 목적의 서버 필드로 만들지 않습니다.

이 목록은 앱의 기본 흐름에 대한 설명입니다. 사용자가 앱 밖에서 운영자에게 직접 이메일을 보내거나 공개 GitHub 이슈에 내용을 입력하면 Support Email 또는 Other User Content가 제공될 수 있습니다. Apple의 고객 지원 관련 선택적 공개 예외에 해당할 수 있는지 최종 제출 시 별도로 검토하고, 지원 흐름이 앱 안으로 바뀌거나 내용이 달라지면 이를 근거로 보편적인 ‘수집하지 않음’을 유지하지 마세요.

광고·app-ads.txt 확인 범위

광고 SDK를 코드에 구성하는 일, App Store Connect의 개인정보 라벨을 제출하는 일, AdMob의 앱 심사와 광고 ID 설정, app-ads.txt의 실제 크롤러 확인은 서로 다른 작업입니다. 이 저장소에는 확인용 app-ads.txt가 있지만, 라이브 호스트 위치와 AdMob 크롤러의 검증 상태는 별도로 확인해야 합니다.

Data collected

Data Collected · Yes

Firebase Analytics and Google Mobile Ads may process app, device, advertising, and diagnostic signals, so review the collection answer as Yes. Journal records and photos are not automatically collected by the app’s core flow to a server, but that does not mean the SDKs process no data.

Keep that vendor flag separate from the app’s no ATT prompt, no IDFA permission request, npa=1, and publisher first-party ID false configuration. On each launch, UMP checks its state and Google determines by region whether a privacy message and choices apply; ad requests run only when canRequestAds permits them, but these facts do not settle Apple’s Tracking answer. “Developer Advertising” is a manifest/store-purpose name; daydot does not run its own marketing campaigns.

Tracking review

Tracking · final review required

The app configuration uses non-personalized ad requests, publisher first-party ID disabled, no ATT tracking permission request, and no IDFA permission request, while the verified GMA manifest reports Device ID as tracking=true. Do not publish Tracking No as a confirmed value until this mismatch is resolved. Verify actual SDK collection, Apple’s Tracking definition, the final compiled release, and the region-specific UMP messages and choices immediately before submission; then update the label to No only when the evidence supports it, or report the result that the final flow requires.

Content not automatically sent by the journal flow

The current app flow is designed not to send these categories in its journal Analytics or advertising events. This is not a claim that every SDK signal is unlinked or anonymous.

  • Photos: PhotosPicker selections are used for on-device entries and are not automatically uploaded.
  • Other User Content: Titles, memos, photos, dates, and search terms are excluded from Analytics events.
  • Contacts: Contacts are not read or uploaded.
  • Precise Location: The app does not request precise-location permission.
  • Financial or Health: The app does not create server fields to collect financial or health data.

This describes the default in-app flow. If a user emails the operator directly or enters content in a public GitHub Issue, Support Email or Other User Content may be provided off-app. Review separately whether Apple’s optional customer-support disclosure exception applies, and update the submission if the support flow moves into the app or changes. Do not rely on a universal “not collected” claim.
